
  # Social Investment Education Platform

  This is a code bundle for Social Investment Education Platform. The original project is available at https://www.figma.com/design/PepiRC8MPjjM8bzyAzF927/Social-Investment-Education-Platform.

  ## Stack

  Vite SPA + React 18 + TypeScript, client-side routing via react-router 7 (`src/app/App.tsx`),
  Tailwind CSS v4, Supabase, deployed on Vercel as a static build (`vercel.json`). Not Next.js —
  there's no App Router, no file-based routing, no server components. `src/app/` is a plain
  folder name, not a Next.js convention.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
